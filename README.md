# resume_chatbot_analyzer-using-llm-api

**AI Resume Analyzer | Python, LLM API, Prompt Engineering**

* Built an AI-powered resume analyzer that extracts candidate skills, experience, education, and other key information from resumes.
* Integrated an LLM API to analyze resumes against a given job description and identify relevant skills, missing skills, and areas for improvement.
* Designed structured prompts and output formats to generate consistent, actionable analysis.
* Implemented a Python-based workflow for document processing, LLM interaction, and presenting analysis to the user.
